# Contributing to AiStack

Thank you for your interest in contributing to AiStack! This document provides guidelines and instructions for contributing.

## How to Contribute

### Reporting Issues

- Use the GitHub issue tracker to report bugs
- Describe the issue clearly, including steps to reproduce
- Include system information (OS, GPU type, Docker version, etc.)

### Submitting Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes with clear, descriptive commits
4. Ensure your code follows the project's coding standards
5. Submit a pull request with a clear description of changes

### Development Setup

1. Install [Docker](https://docs.docker.com/engine/install/)
2. Clone the repository
3. Run `make package` to build

### Code Style

- Follow existing code conventions in the project
- Write clear comments for complex logic
- Include tests for new features

## Code of Conduct

Please be respectful and constructive in all interactions. We are committed to providing a welcoming and inclusive experience for everyone.
