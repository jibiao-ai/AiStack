## AiStack — 企业级 AI 推理集群管理平台

### 产品简介

AiStack 是一款面向企业私有化部署的 AI 推理集群管理平台，提供 GPU 集群的统一管理、推理引擎的自动化编排以及 GPU 实例的按需供给能力。平台支持 vLLM、SGLang、TensorRT-LLM 等主流推理引擎，兼容 NVIDIA、AMD、华为昇腾、海光、摩尔线程、寒武纪等多种 GPU/加速器硬件，充分复用企业现有硬件资源。

### 产品定位

面向企业内部 AI 推理集群运维场景，解决以下核心问题：
- 多厂商、多型号 GPU 硬件的统一纳管与调度
- 大模型推理服务的快速部署、弹性扩缩与性能调优
- 异构硬件环境下存量 GPU 资源的利旧与整合
- 企业级权限管控、监控告警与运维保障

### 核心能力

| 能力模块 | 说明 |
|---------|------|
| **多集群统一管理** | 跨物理机、K8s、云端环境的 GPU 集群统一纳管与调度 |
| **可插拔推理引擎** | 自动配置 vLLM / SGLang / TensorRT-LLM 等引擎，支持自定义引擎接入 |
| **Day 0 模型支持** | 新模型发布当天即可部署上线，无需等待平台版本更新 |
| **性能自动调优** | 预调优模式 + KV Cache 扩展 + 推测解码，开箱即用的高性能推理 |
| **GPU 实例供给** | 按需启动 SSH 可访问的 GPU 实例，用于开发调试与微调任务 |
| **广泛硬件兼容** | 兼容 NVIDIA / AMD / 昇腾 / 海光 / 摩尔线程 / 寒武纪等主流加速器 |
| **OpenAI 兼容 API** | 提供标准 OpenAI 兼容 API，支持 LLM / 语音 / 图像 / 视频模型 |
| **企业级运维** | 故障自愈、负载均衡、Grafana/Prometheus 监控、RBAC 权限控制 |

### 适用场景

1. **私有化 AI 推理平台建设** — 企业内网环境搭建统一的大模型推理服务平台
2. **存量 GPU 利旧整合** — 将分散在各业务部门的异构 GPU 资源统一纳管、池化调度
3. **多模型统一服务** — 一套平台同时承载 LLM 对话、文生图、语音识别等多类模型
4. **开发测试环境供给** — 为 AI 开发团队按需提供 GPU 实例，提升开发效率
5. **边缘推理节点管理** — 管理分布在多个机房/边缘节点的 GPU 推理集群

### 技术栈

- 后端：Go / Python
- 推理引擎：vLLM / SGLang / TensorRT-LLM（可插拔）
- 容器化：Docker
- 监控：Grafana + Prometheus
- 许可证：Apache License 2.0
